🎯 OGGI - PREPARAZIONE

1. Esegui lo scraper (estrae dati dal forum):
   cd forum-migration
   python scraper.py

2. Verifica che ha generato i file:
   - forum_data.json (discussioni e post)
   - users.csv (lista utenti)

3. Apri la demo nel browser:
   Doppio click su: forum-migration/public/index.html

================================================================================

🎬 DOMANI - PRESENTAZIONE

Sequenza:
1. Apri public/index.html nel browser
2. Leggi PRESENTAZIONE_CLIENTE.md
3. Mostra forum_data.json e users.csv
4. Rispondi a domande
5. Ottieni approvazione

================================================================================

📦 DOPO APPROVAZIONE - IMPLEMENTAZIONE

Fase 1: Setup Flarum
   bash flarum-setup.sh

Fase 2: Configura database
   Modifica .env con credenziali MySQL

Fase 3: Import utenti
   php artisan tinker < import-users.php

Fase 4: Deploy preview Firebase
   firebase init hosting
   firebase deploy

Fase 5: Deploy produzione Register
   Leggi: register-deployment.md

🆘 TROUBLESHOOTING RAPIDO

Scraper non funziona:
   → Verifica connessione internet
   → Verifica che BeautifulSoup è installato
   → Prova: pip install requests beautifulsoup4

Flarum non installa:
   → Verifica PHP 8.0+
   → Verifica Composer installato
   → Prova: composer create-project flarum/flarum .

Database non connette:
   → Verifica credenziali .env
   → Verifica MySQL running
   → Prova: mysql -u user -p -h localhost database

Firebase deploy fallisce:
   → Verifica: firebase login
   → Verifica: firebase init
   → Prova: firebase deploy --force
