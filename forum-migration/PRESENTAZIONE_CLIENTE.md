```

├── Discussioni

└── Metadati
```

### Step 2: Preparazione Nuova Piattaforma
```
Flarum setup
├── Database
├── Configurazione
├── Tema personalizzato
└── Estensioni
```

### Step 3: Import Dati
```
Dati backup → Flarum
├── Utenti (con reset password)
├── Discussioni
├── Post
└── Allegati
```

## ❓ Domande Frequenti

**D: Perderemo i dati attuali?**
R: No! Tutti i dati vengono migrati completamente. Facciamo backup prima di iniziare.

**D: Gli utenti dovranno registrarsi di nuovo?**
R: No! Manteniamo gli stessi username. Reimpostano solo la password (per sicurezza).

**D: Quanto tempo sarà offline il forum?**
R: Massimo 1-2 ore durante il deploy finale. Comunichiamo in anticipo.

**D: Possiamo tornare indietro se non piace?**
R: Sì, abbiamo backup completi. Ma siamo sicuri che piacerà! 😊

**D: Cosa succede ai messaggi privati?**
R: Per privacy, non vengono trasferiti. Gli utenti possono contattarsi via email.

**D: Avremo supporto dopo il launch?**
R: Sì! Supporto 24h per le prime 2 settimane, poi supporto standard.
